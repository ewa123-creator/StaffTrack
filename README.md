### Сущности

| Сущность | Назначение | Ключи |
|---|---|---|
| `employees` | Сотрудники | **PK** employee_id, UNIQUE personnel_number |
| `positions` | Должности | **PK** position_id |
| `assignments` | Назначения | **PK** assignment_id, **FK** → employees, positions |
| `managers` | Руководители подразделений | **PK** manager_id, **FK** → employees |
## Архитектура проекта (ЛР4)

Проект реализован по многослойной архитектуре:

- **`src/models/`** — модели данных (dataclass): Employee, Position, Assignment, Manager
- **`src/repositories/`** — слой доступа к БД (CRUD-операции для каждой таблицы)
- **`src/services/`** — бизнес-логика (проверка свободных ставок, увольнение, авторизация)
- **`src/ui/`** — консольный интерфейс (меню, авторизация)

### Роли пользователей

|---|---|---|---|

## Регистрация и авторизация

В системе реализована авторизация по логину и паролю. 
Сотрудники **не могут самостоятельно зарегистрироваться**. 
Новых пользователей создает **Кадровик** при добавлении карточки нового сотрудника. 
При создании сотрудника Кадровик задает ему логин и пароль.

### Связи
- `managers` **1 : 1** `employees` — руководитель это сотрудник
- `employees` **1 : N** `assignments`
- `positions` **1 : N** `assignments`
- `employees` **M : N** `positions` (через `assignments`)
